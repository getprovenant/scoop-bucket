# Provenant Scoop bucket

[Scoop](https://scoop.sh) manifest for [Provenant](https://github.com/getprovenant/provenant), a fast Rust code scanner for licenses, copyrights, and package provenance.

## Install

```powershell
scoop bucket add provenant https://github.com/getprovenant/scoop-bucket
scoop install provenant
```

## What you get

The prebuilt Windows (x86_64) binary from the [Provenant release archives](https://github.com/getprovenant/provenant/releases), with its SHA-256 checked by Scoop. The manifest is bumped automatically on every Provenant release.

For usage, see the [Provenant website](https://getprovenant.dev), the [Provenant README](https://github.com/getprovenant/provenant#readme), and the [CLI Guide](https://github.com/getprovenant/provenant/blob/main/docs/CLI_GUIDE.md).
